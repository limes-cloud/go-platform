# 06 数据源与插件

## 1. 问题背景

现有代码里，「所属应用」这一个下拉导致 `ListApp` 被引用 **29 次、约 14 个页面各自重写一遍 `loadApps`**。同类还有 `ListEntity`(12)、`ListJob`(10)、`ListCurrentDept`(10)。

而且现有 options 的三种来源写法不统一：写死字面量 16 处、来自 `ref.value` 12 处、来自裸 reactive 变量 9 处（有无 `.value` 混用）。项目**没有字典 store**——`manager/dictionary` 模块只做 CRUD 管理，从不驱动 options。

## 2. OptionsSource

```ts
type OptionsSource =
  | Array<{ label: string; value: any; [k: string]: any }>   // ① 字面量
  | RemoteSource                                             // ② 远程
  | { from: 'self'; rootLabel?: string; rootValue?: any }     // ③ 引用本表格数据

interface RemoteSource {
  plugin: '$options'
  api: EndpointSpec                  // 或 model: string 走约定
  labelField?: string                // 默认 'name'
  valueField?: string                // 默认 'id'
  dataPath?: string                  // 默认由 tableConfig.recordFields 探测
  params?: Record<string, any>
  dependsOn?: string                 // 依赖另一个字段的值，该值变化时重取
  remoteThreshold?: number           // 超过则转远程搜索，默认 50
  cacheKey?: string                  // 同 key 的请求在单次编译内共享
}
```

### `{ from: 'self' }` — 自引用树

专门解决现有 4 处模式（`manager/dept`、`manager/role`、`manager/app/menu`、`recipe/recipe/classify`）：

```ts
// 现状：手写在 computed 里
data: [{ id: 0, name: '顶级部门', children: data.value }]

// 协议
parentId: { label:'上级部门', type:'number', component:'treeselect',
            dataSource: { from:'self', rootLabel:'顶级部门', rootValue:0 } }
```

页壳在渲染表单时把当前表格 `data` 注入。**这是标为低确定性的一项**（时序/循环依赖风险），plan_b 见 [16](16-决策记录.md)。

## 3. Plugin marker 机制

借 alien-form `compiler/resolve.ts` + `plugins.ts`。规则：**schema 里任意位置出现形如 `{ plugin: "$xxx", ... }` 的对象，就是一个插件调用点**，按名字派发，用返回值替换该位置。

```ts
interface CompilePlugin {
  name: string                                        // '$options'
  /** prefetch 阶段：声明要预取什么，结果写进 store */
  prefetch?: (marker: any, ctx: PrefetchCtx) => Promise<void>
  /** resolve 阶段：返回替换值；返回 undefined 表示删除该位置 */
  resolve: (marker: any, ctx: ResolveCtx) => Promise<any>
}
```

两条硬规则：

1. **未注册的插件 marker 必须被删除并记录错误**，不能把 `{plugin:...}` 泄漏进渲染层（alien-form 用 `deletePath` 处理，`resolve.ts:66-70`）
2. **预取结果放单次编译的 `store`，不放模块级缓存**——否则跨模型串数据

## 4. 场景分化：同一个 marker 解析成不同东西

这是 alien-form 最聪明的一处设计（`plugins.ts:77-104`），直接命中我们的需求：

| 场景 | `$options` 解析结果 | 用途 |
|---|---|---|
| `table` | 预取好的**选项数组** | 把外键 id 翻译成 label（表格显示「研发部」而不是 `3`） |
| `search` | 预取好的**选项数组** | 搜索下拉直接可选 |
| `form` + 选项 ≤ 阈值 | 预取好的**选项数组** | 一次性下发 |
| `form` + 选项 > 阈值 | **`{ service }` 声明**，`dataSource` 置空 | 组件自己远程搜索 |

```ts
resolve: async (marker, ctx) => {
  const options = await readOptions(marker, ctx)          // 命中 store 缓存
  if (ctx.scene !== 'form') return options                // 表格/搜索：注入字典
  if (options.length <= (marker.remoteThreshold ?? 50)) return options
  // 超阈值：注入纯数据 service 声明，组件自取
  ctx.patch([...ctx.path.slice(0, -1), 'props', 'service'], {
    api: marker.api, labelField: marker.labelField ?? 'name',
    valueField: marker.valueField ?? 'id', remoteSearch: true,
  })
  return undefined
}
```

**关键约束：注入的 `service` 必须是纯可序列化数据，不含闭包。** 请求能力由页壳通过 `provide/inject` 注入。这样编译产物才能被缓存、被 JSON 化、被存到后端。

「外键 id → label」在后台系统是高频刚需，这个方案比在每列写 formatter 干净得多——**一处声明同时服务表格翻译、搜索下拉、表单选项三件事**。

## 5. `dependsOn` — 级联选项

现有 2 处联动（`configure/template` 选 app → 重拉 namespace；`manager/role/entity` 的 app→entity→fields 四级链）：

```ts
namespace: {
  label: '命名空间', type: 'string', component: 'select',
  dataSource: { plugin: '$options', api: {...}, dependsOn: 'app', params: { app: '$dep' } }
}
```

语义：`app` 字段值变化 → 用新值重取选项 → 清空本字段当前值（若不在新选项内）。

**`dependsOn` 的选项不在编译期预取**（编译期不知道 `app` 的运行时值），而是编译成 `service` 声明由组件运行时取。这是 `dependsOn` 与普通 `$options` 的根本区别。

四级级联那种（`manager/role/entity`，442 行）超出声明式范围，该页留本地 `.vue`。

## 6. 选项变化后旧值怎么办

alien-form 有 `dataSourcePolicy` 四个策略，但 `clear` 和 `filter` 两个分支实现完全一样（`form.ts:117-122`），实际只需要一个。我们只做一条：

**选项变化后，若当前值不在新选项中，清空该值。** 不提供配置项。

多选字段则过滤掉不在新选项中的项，保留其余。

## 7. 缓存分层

| 层 | 作用域 | 内容 |
|---|---|---|
| `store` | 单次 `compile()` | 三场景共享的预取字典，避免同一个 `$options` 拉三次 |
| 编译产物缓存 | 页面生命周期 | `Compiled` 对象。key = schema 标识 + version。用 VueUse `useMemoize` 或 TanStack Query Vue |
| 组件级远程搜索 | 组件实例 | `service` 声明触发的运行时请求，各组件自管 |

**编译产物必须进缓存**（alien-form 用 react-query，`use-compiled.ts`）——外键预取有网络开销，不能每次开弹窗重编译一遍。

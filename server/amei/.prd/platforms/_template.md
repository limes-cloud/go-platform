## 1. 基本信息

- 平台名称、主体、内容形态；
- 开放平台入口、开发者协议；
- 是否要求企业主体、实名、行业资质；
- 是否有测试应用/沙箱。

## 2. 手机号与账号注册

必须分开写：

### 2.1 amei 用户

- amei 自身手机号 OTP 注册/登录，统一走 `03-phone-auth.md`。

### 2.2 平台开发者账号

- 注册入口；
- 是否支持手机号注册；
- 验证码、实名、企业资质；
- 是否需要绑定微信/邮箱；
- 证据 URL 和验证状态。

### 2.3 平台内容账号

- 用户如何登录开放平台授权；
- 扫码、OAuth、手机号 App 内确认；
- 服务端是否能用手机号+验证码直接登录：`是/否/未核实`；
- 是否需要账号实名或内容发布资格。

## 3. 开放平台授权

- OAuth 入口；
- 授权参数、scope、回调；
- access token / refresh token 有效期；
- 撤销授权方式；
- 应用审核和权限申请。

## 8. 发布与审核状态

- 创建成功返回什么 ID；
- 是否有审核状态接口；
- 审核中/公开/拒绝如何区分；
- 超时如何查询；
- 是否支持删除/撤回。

## 9. 数据指标

- 作品级接口；
- 账号级接口；
- 字段字典；
- 是否累计值；
- 更新延迟；
- 权限要求。

## 10. 自动化可行性

- 服务端全自动；
- 需要用户扫码/确认；
- 仅应用内操作；
- 无公开 API；
- 本期不提供网页自动化；此处只记录官方开放 API 的授权和发布边界。

## 11. 人工接管点

## 12. 风险与合规

- 平台协议；

- 额度/风控；

## 1. 结论

当前小红书开放平台文档导航只有电商和商家相关 API，没有发现笔记、图文或视频内容发布接口。不能把商家、订单、商品、营销 API 当作内容发布能力。

本期不做自动发布。保留平台能力占位、账号入口调研和人工运营说明，待官方确认后再排期。

## 9. 风险

- 电商 API 容易被误认为内容 API；
- 逆向/网页自动化违反平台条款和账号风控；
- 小红书对营销、外链和导流审核严格；
- 书籍推广内容需要避免硬广和违规导流；
- 在没有官方接口前承诺自动发布，会直接阻塞交付。

## 10. 适配器实现建议

1. 只实现 `capabilities` 占位和禁用状态；
2. 不实现发布、素材上传、数据拉取；
3. 记录官方文档变更；
4. 与平台官方渠道确认内容发布权限；
5. 确认后重新出接口调研和测试计划；
6. 不把电商 token 当内容发布 token。

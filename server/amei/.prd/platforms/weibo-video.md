# 微博开放平台调研

> 平台：微博
> 平台编码：`weibo`
> 官方入口：https://open.weibo.com/
> 调研日期：2026-11-12
> 总体状态：文本/图片分享 `已核实`；视频开放范围 `已核实`，个人不可接入，机构需单独开通

## 1. 结论

微博有可用的 OAuth 和文本/图片分享接口，适合做书评摘要、图文卡片和带链接的短内容。视频上传不是普通开发者能力：官方说明接入方必须是政务、媒体、机构等实体，个人暂时无法接入。

微博与抖音、快手不同，`statuses/share` 强制要求至少一个第三方网页 URL，且 URL 必须属于调用应用绑定的安全域。这会直接影响 PSou 引流链接设计。

## 2. 手机号与账号注册

### 2.1 amei 用户

amei 手机号 OTP 注册/登录，与微博账号无关。

### 2.2 微博开发者账号

- 开放平台入口存在；
- 是否支持手机号注册、是否需要企业资质：`登录后可见/待验证`；
- 应用创建、安全域名、回调地址和接口权限需登录后台配置；
- 普通微博账号不等于有开放平台接口权限。

### 2.3 微博内容账号

- 用户通过 OAuth 授权；
- access token 由适配器保存；
- 不支持服务端用手机号+验证码直接登录微博；
- 开发者应用必须绑定安全域名，否则 `statuses/share` 的 URL 会被拒绝。

## 3. OAuth

已核实文档入口：

```text
https://open.weibo.com/wiki/2/statuses/share
https://open.weibo.com/wiki/2/statuses/upload_url_text
```

需要确认：

- authorize URL 和应用 key/secret；
- redirect URI；
- access token 有效期；
- refresh/重新授权；
- scope 与接口访问级别；
- 应用安全域名。

## 4. 文本/图片接口

### 4.1 `statuses/share`

```http
POST https://api.weibo.com/2/statuses/share.json
```

参数：

| 字段 | 必填 | 约束 | 说明 |
| --- | --- | --- | --- |
| `access_token` | 是 | OAuth token | 适配器注入 |
| `status` | 是 | 不超过 140 个汉字，不能含 `#话题词#` | 必须包含至少一个第三方网页 URL |
| `pic` | 否 | JPEG/GIF/PNG，小于 5 MB | multipart/form-data 上传 |
| `rip` | 是 | 真实操作用户 IP | 不能伪造 |

关键约束：

- 正文必须包含至少一个第三方网页 URL；
- URL 必须属于调用方应用绑定的安全域；
- 正文不能含 `#话题词#`；
- 不支持直接用长文；
- 连续发布不能完全相同；
- 有频次限制。

### 4.2 `statuses/upload_url_text`

```http
POST https://api.weibo.com/2/statuses/upload_url_text.json
```

这是高级接口，需要额外授权/频次权限。文档中可见：

- 默认文本不超过 140 个汉字；
- `is_long_text=1` 可发送长文；
- 支持最多 9 个 `pic_id`；
- 有频次限制。

如果应用没有高级权限，不能把它作为默认发布路径。

## 5. 视频发布

官方页面：

```text
https://open.weibo.com/wiki/Video/api
```

已核实内容：

- 微博为自媒体作者、机构、具备拍摄能力的硬件厂商提供短视频上传/发布接口；
- 接入第三方必须是政务、媒体、机构等实体，个人暂时无法接入；
- 需联系对应的蓝 V 客服或政务运营洽谈，开通视频上传接口并获取文档。

因此：

- 视频端点、字段、格式、大小、时长和审核状态不在公开文档中，标记 `未核实/待补充`；
- 不能根据旧博客或社区代码猜接口；
- 本期视频开关默认 `false`；
- 只有具备机构资质并完成商务/接口开通后，才进入适配器实现；
- `https://open.weibo.com/wiki/2/video/upload` 的空页面不能作为“接口不存在”或“接口可用”的证据。

## 7. 内容能力

| 类型 | 状态 | 说明 |
| --- | --- | --- |
| 文本 | 已核实 | 140 字，需 URL |
| 图片 | 已核实 | JPEG/GIF/PNG，<5 MB，最多 9 张需对应接口权限 |
| 视频 | 仅机构可申请 | 个人不可接入；需蓝 V/政务运营开通 |
| 文章 | 以长文微博替代 | `is_long_text=1` 需权限 |

## 8. 素材与字段映射

- 图片先经 `amei-media` 压缩和 EXIF 清理；
- 适配器以 multipart 上传 `pic`，或先上传图片取 `pic_id`；
- 正文中插入绑定安全域的 PSou URL；
- URL 必须属于应用安全域名，否则不要创建任务；
- 微博话题语法与普通标签不同，适配器需避免把 `#话题#` 带入 `statuses/share` 的受限位置；
- 商业推广内容和外链需按微博规则标识。

## 9. 审核与状态

已核实：分享接口返回微博 ID、`mid`、文本、图片等字段，可保存为 `platformPostId`。

未核实：

- 审核状态查询；
- 发布后删除/撤回；
- 视频审核；
- 作品级数据接口；
- 账号数据接口。

没有状态接口时，`published` 只能表示“平台创建接口成功”，不能保证已公开。

## 10. 数据指标

文本分享接口返回值主要是微博内容和用户信息，不包含完整作品指标。数据接口权限、字段和频次均需进一步确认。

可人工补录：

- 阅读；
- 转发；
- 评论；
- 点赞；
- 收藏。

补录数据标记 `source=manual_csv/platform_export`。

## 11. 自动化可行性

- 文本/图片发布：官方 API，可在权限获批后自动；
- 视频发布：暂不自动；
- 用户登录：OAuth；
- 手机号注册：`登录后可见/待验证`；
- 网页模拟登录：不作为生产方案；
- 额度：接口有限频，具体数值未核实。

## 12. 人工接管点

- OAuth 授权/过期；
- 安全域名未配置；
- 高级接口权限不足；
- 内容审核；
- 外链/商业推广被拒；
- 视频能力待开通。

## 13. 风险

- 正文必须带 URL，纯文案发布不适用；
- URL 安全域错误会直接失败；
- 140 字和长文权限不同；
- 连续相同内容会被拒绝；
- 视频只对机构开放，个人账号默认不可用；
- 社区仓库最后提交时间较早，签名/参数需以官方文档校正。

## 14. 适配器实现建议

1. 先实现 OAuth 和 `statuses/share`；
2. 正文/URL 安全域校验放在提交前；
3. 图片上传走 `amei-media` 清洗后的副本；
4. `upload_url_text` 需确认高级权限后再启用；
5. 视频保持 `supported=false`；
6. 指标不支持时只允许人工导入；
7. 不采用网页登录获取授权码的实现。

# 视频号开放能力调研

> 平台：微信视频号
> 平台编码：`wechat_channels`
> 官方入口：https://channels.weixin.qq.com/platform
> 开发文档：https://developers.weixin.qq.com/doc/channels/index.md
> 调研日期：2026-11-12
> 总体状态：公开视频内容发布 API `无公开 API/未核实`

## 1. 结论

当前官方视频号开发文档只确认了视频号小店/交易/商家相关能力，没有确认公开的短视频内容发布 API。服务端不能通过“猜一个接口”或复用微信小程序/公众号接口来发布视频号内容。

首版不做自动发布，也不使用抓包、下载、逆向或网页自动化。

## 2. 手机号与账号注册

### 2.1 amei 用户

amei 手机号 OTP 注册/登录，不依赖微信。

### 2.2 视频号开发者/商家账号

- 官方入口和商家后台存在；
- 是否支持手机号单独注册、是否必须绑定微信、企业资质要求：`未核实/待补充`；
- 视频号小店与视频号内容账号不是同一套权限；
- 开通小店能力不等于能通过 API 发视频。

### 2.3 视频号内容账号

- 用户通常在微信/视频号后台完成登录和身份验证；
- 是否有第三方 OAuth 授权发布能力：`未核实/待补充`；
- 仅应用内操作/平台后台发布：可能性高，但当前不能作为已核实结论；
- 服务端不应保存用户微信密码或扫码登录状态。

## 3. 官方文档现有范围

已核实文档入口覆盖：

- 视频号小店；
- 商家商品/订单/交易相关能力；
- 本地生活商家相关规则入口。

未发现：

- 视频内容上传 API；
- 视频创建/发布 API；
- 作品列表/审核状态 API；
- 内容播放/互动数据 API；
- 第三方账号 OAuth 发布 scope。

这些能力不能从“公众号”或“小程序”文档外推。

## 5. GitHub 调研

未找到可确认的官方内容发布 SDK。不建议参考或引入以下类型项目：

- 抓包/逆向视频号上传；
- 自动下载视频号内容；
- 通过网页后台模拟发布；
- 共享登录态/扫码凭证。

原因：

- 可能违反平台条款；
- 账号风控严重；
- 无法稳定维护；
- 无法提供合法 API 配额和审核状态；
- 商业产品不能把逆向接口当基础设施。

## 7. 自动化可行性

- 官方服务端发布：当前不可判定；
- 用户授权：`未核实/待补充`；
- 手机号注册：`未核实/待补充`；
- 仅应用内操作：待确认；
- 网页自动化：禁用；
- 逆向/抓包：禁止。

## 8. 人工接管点

- 视频号后台登录；
- 微信身份验证；
- 视频号认证/资质；
- 内容上传与发布；
- 审核；
- 数据导出。

## 9. 风险

- 把视频号小店能力误当成内容发布 API；
- 用公众号/小程序接口外推视频号；
- 网页自动化和逆向导致封号；
- 内容版权、音乐版权和商业推广审核；
- 无法自动化时仍需产品明确“仅人工发布”。

## 10. 适配器实现建议

1. 只做能力占位和禁用；
2. 不实现 token、素材上传、发布、取数；
3. 持续跟踪官方文档；
4. 如确认有 API，先补权限、OAuth、上传、审核、数据五项证据；
5. 若只能人工发布，则在 amei 中提供任务清单和回填链接，不假装自动发布。

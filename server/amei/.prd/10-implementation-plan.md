# 实施计划

> 状态：方案设计
> 日期：2026-11-12
> 目标：先完成官方开放平台闭环，再扩展多平台；不以平台数量作为首期目标

## 1. 开工前置条件

编码前需要确认：

1. 抖音、快手、B 站、微博开发者应用是否已创建；
2. 每个应用是否拿到内容发布、素材上传、作品数据权限；
3. OAuth 回调域名和备案主体；
4. 生产短信通道、模板和签名；
5. `amei-media`、`amei-adapters` 的仓库归属和部署环境；
6. 书籍封面、作者照片、出版社素材的授权边界；
7. 平台账号由用户自己授权，还是运营统一管理；
8. 小红书、视频号是否已有官方合作/开放能力，未确认前不排自动发布。

未满足前置条件的平台只能做能力展示和禁用占位，不能以网页后台、Cookie 或逆向接口临时顶上。

## 2. 阶段计划

### M0：调研与协议冻结

交付：

- 本文档目录；
- 平台调研、GitHub 许可和覆盖结论；
- 三层仓库边界；
- 适配器协议、内容模型、媒体模型。

验收：

- 所有平台事实带来源和验证状态；
- 社区/逆向实现没有被写成官方能力；
- 额度未知项明确标记；
- 明确不做网页自动化，所有发布路径均为开放平台 API。

### M1：控制面与手机号登录

交付：

- `amei` 服务骨架；
- 手机号 OTP 注册/登录；
- JWT/会话鉴权；
- 用户、内容、平台账号、适配器注册基础表；
- 短信 provider 抽象。

验收：

- 新手机号首次验证码登录自动建号；
- 重发、过期、错误次数和日志脱敏通过；
- 可配置切换 `dev`/`webhook` 短信通道；
- 用户隔离和唯一索引测试通过。

### M2：独立媒体层

交付：

- `amei-media` 独立仓库；
- 直传票据、上传完成回调；
- 图片/视频探测、转码、封面、字幕；
- 私有对象存储和签名 URL；
- 资产状态机和哈希去重；
- 与控制面的素材引用协议。

验收：

- 支持文章配图、图文图集、短视频；
- 非法 MIME、超大文件、超长视频、损坏文件被拒绝；
- 转码前后元数据正确；
- 签名 URL 过期后不可访问；
- 控制面不保存大文件。

### M3：抖音官方闭环

交付：

- 复用 `bytedance/douyin-openapi-sdk-go`；
- OAuth 授权、token 加密、刷新、解绑；
- 视频/图文素材上传；
- 视频发布、图文发布；
- 发布状态和作品 ID 回写；
- 作品/账号指标拉取；
- 抖音适配器能力声明。

验收：

- 测试账号完成一次视频发布和一次图文发布；
- 平台作品 ID/URL 可回写；
- 重复提交不重复发布；
- token 不出适配器；
- 指标与平台后台人工对账；
- 权限不足时明确返回 `PERMISSION_DENIED`。

### M4：批量发布与数据看板

交付：

- 发布批次、任务拆分、失败隔离；
- 定时发布、重试、取消；
- 任务状态查询和人工接管；
- 指标聚合、来源、新鲜度和缺失字段展示；
- 发布成功率、审核拒绝率、人工接管率。

验收：

- 一个内容版本可发多个平台账号；
- 单平台失败不影响其他任务；
- 重启后任务和定时不丢失；
- 分批重试不造成重复发布；
- 指标缺失显示“未提供”，不显示 0。

### M5：快手验证适配器

交付：

- 按当前官方文档复核 `bububa/kwai-openapi` 的端点和字段；
- OAuth2 授权；
- 视频 start/upload/complete/publish/list；
- 作品基础指标；
- 社区 SDK 与官方文档差异清单。

验收：

- 测试应用完成视频上传和发布；
- 旧 SDK 端点与当前官方文档不一致时以官方文档为准；
- 不直接依赖 2021 年社区库作为生产唯一实现；
- 数据接口权限明确。

### M6：B 站与微博能力补齐

B 站：

- 申请开放平台稿件投递权限；
- 用测试应用确认 query 参数与 HMAC-SHA256 签名头的最终鉴权方式；
- 实现 token 换发、视频 init/8 MiB 分片/complete、封面、分区和 `add-by-utoken`；
- 保存 `resource_id`，状态未知时标 `pending_review`；
- 非正式会员 5 条/日额度展示；
- 数据接口未核实前不承诺作品数据。

微博：

- OAuth 授权；
- `statuses/share` 文本/图片；
- `statuses/upload_url_text` 长文/最多 9 张图（需权限）；
- 视频只对已完成机构资质和蓝 V/政务运营开通的账号配置，个人账号保持关闭。

验收：

- 两个平台的成功/失败/权限不足三类路径可区分；
- 不把 Web/Studio 接口冒充开放平台 API；
- 图片尺寸、正文长度、URL 安全域在提交前校验。

### M7：小红书与视频号能力确认

只做：

- 开发者入口、账号授权状态、能力展示；
- 监控官方开放平台文档更新；
- 与平台商务/开发者支持确认内容发布权限；
- 若确认无 API，则保持禁用，不提供网页自动化。

不交付：

- 抓包、逆向、自动下载、浏览器批量发布；
- 未经许可的账号养号和代理切换。

## 3. 依赖

| 依赖 | 用途 | 风险 |
| --- | --- | --- |
| 平台开发者应用 | OAuth、发布、数据权限 | 审核周期、主体资质、权限不批 |
| 短信供应商 | amei 手机号登录 | 模板报备、签名、限流 |
| MySQL/Redis | 业务与任务 | 备份、容量、锁 |
| 对象存储/CDN | 媒体 | 私有桶、签名、转码成本 |
| 转码 worker | 视频规格统一 | CPU/GPU、时长、并发 |
| 内容与版权 | 书籍简介/书评/封面 | 侵权、平台审核 |
| 平台运营账号 | 实号测试 | 封禁、实名、额度 |

## 4. 测试策略

### 控制面

- OTP/JWT 单元测试；
- 用户隔离、账号唯一约束；
- 批次/任务状态机；
- 幂等键和并发提交；
- 定时任务恢复；
- 指标 upsert 与缺失字段；
- 适配器超时、5xx、重复回调。

### 媒体层

- MIME/大小/时长/分辨率；
- 转码、封面、字幕；
- 哈希去重；
- 签名 URL 过期；
- 恶意文件和异常媒体；
- 对象存储故障恢复。

### 适配器

- 协议契约测试；
- OAuth state、回调、刷新和撤销；
- 平台签名；
- 素材上传和发布幂等；
- 审核中/拒绝/限流/权限不足；
- 日志脱敏；
- 官方 SDK 版本升级回归。

### 联调

- 测试账号小流量；
- 单平台发布后人工核对 URL 和后台状态；
- 指标与平台后台人工对账；
- 多平台批次失败隔离；
- 真实网络抖动和超时测试。

## 5. 验收总表

| 能力 | 验收标准 |
| --- | --- |
| 手机号注册/登录 | 首次自动建号、验证码限流、JWT 鉴权 |
| 平台账号管理 | 一个手机号多平台账号，OAuth 凭据不落控制面 |
| 媒体层 | 独立仓库，图片/视频上传、转码、签名 URL |
| 一键发布 | 一次提交多平台任务，单平台失败隔离 |
| 平台自适应 | 控制面只传通用内容，适配器映射字段和素材 |
| 文章/图文/视频 | 三种类型都有模型和适配器能力声明 |
| 数据拉取 | 官方 API + 人工补录，幂等，区分 0 与未知 |
| 审核/接管 | 审核中、重授权、人工确认可区分 |
| 安全 | token 只在适配器、日志脱敏、最小权限 |
| 可运维 | 独立部署、健康检查、告警、回滚 |

## 6. 关键风险

| 风险 | 影响 | 应对 |
| --- | --- | --- |
| 平台权限不批 | 无法自动发布 | 先确认权限，再做适配器；不承诺全覆盖 |
| 官方文档登录后可见 | 研究不完整 | 明确待验证，登录后台补证 |
| 平台接口变更 | 适配器失效 | 独立版本、契约测试、快速回滚 |
| 视频规格复杂 | 发布失败/审核慢 | 媒体层统一母版 + 平台派生版本 |
| OAuth token 失效 | 批量任务中断 | 状态探测、重新授权、单任务暂停 |
| 版权/广告合规 | 下架、封号 | 素材授权、商业标识、敏感词提示 |
| 社区 SDK 过期 | 集成错误 | 只作参考，官方文档优先 |
| 重复内容 | 平台限流/拒绝 | 内容版本化、平台差异化、频控 |

## 7. 本期不做

- 一次接完所有内容平台；
- 自动注册平台账号、养号、自动换号；
- 验证码识别、风控绕过、逆向接口；
- 自动洗稿和批量伪原创；
- 评论、私信、点赞自动化；
- 广告投放和付费推广；
- 多租户计费；
- 全量旧数据迁移。

## 8. 交付顺序结论

```text
调研与协议
  -> 控制面 + 手机号登录
  -> 独立媒体层
  -> 抖音官方 SDK 闭环
  -> 批量发布与数据看板
  -> 快手验证
  -> B 站/微博补齐
  -> 小红书/视频号能力确认
```

抖音先行的原因不是“更容易做网页”，而是它已有可核实的官方 SDK 和发布链路，能最早验证 amei 的统一协议。

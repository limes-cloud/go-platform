# 部署与安全

> 状态：方案设计
> 日期：2026-11-12
> 范围：三层服务部署、网络安全、OAuth 凭据、媒体安全、内容合规和运维

## 1. 部署单元

| 服务 | 职责 | 公网暴露 |
| --- | --- | --- |
| `amei-api` | 用户 API、后台、鉴权、账号索引、发布编排 | 是，经 HTTPS/WAF |
| `amei-worker` | 定时、重试、状态轮询、指标调度 | 否 |
| `amei-media-api` | 上传票据、媒体状态、签名 URL | 可公网，需鉴权/限流 |
| `amei-media-worker` | 转码、封面、字幕、病毒扫描 | 否 |
| `amei-adapter-*` | 每个平台的 OAuth、素材、发布、取数 | 平台回调入口需要受控公网域名 |
| MySQL | 业务数据 | 否 |
| Redis | 锁、限流、短任务队列 | 否 |
| 对象存储 | 私有媒体桶 | 仅签名 URL / CDN 回源 |

适配器按平台独立部署，避免一个平台升级或崩溃拖垮其他平台。平台回调域名可由统一网关路由到适配器。

## 2. 网络拓扑

```text
Browser/App
  │ HTTPS
  ▼
WAF / Nginx
  ├─► amei-api ───────────────► MySQL / Redis
  ├─► amei-media-api ─────────► Object Storage
  └─► oauth callback gateway ─► amei-adapter-*
                                  ├─► 平台官方 API
                                  ├─► amei-media signed URL
                                  └─► adapter MySQL/Postgres + KMS
```

- 控制面与适配器只走内网 mTLS 或服务 token；
- 适配器不能直接访问控制面主库；
- 平台 OAuth 回调必须校验 `state`、时间戳、签名和会话绑定；
- 出站只允许平台官方域名、对象存储和短信网关白名单；
- 生产禁止共享平台账号或跨用户复用 token。

## 3. OAuth 凭据安全

平台 OAuth token 只存在适配器：

- access token、refresh token 使用 KMS/信封加密；
- 加密密钥与数据库分离，按平台和环境隔离；
- token 不写日志、不返回控制面、不写前端 localStorage；
- 保存 `scope`、过期时间、刷新时间和最近错误；
- refresh 失败标记 `expired`，要求用户重新授权；
- 解绑时删除 token 并调用平台撤销接口（平台支持时）；
- 适配器备份加密数据库，恢复后验证密钥可用。

禁止：

- 在控制面创建 `platform_token` 表；
- 用手机号+密码模拟平台登录；
- 保存平台 cookie、二维码 seed、浏览器 storage state；
- 将 token 放进 URL query 或错误堆栈。

## 4. 手机号 OTP 安全

沿用 `03-phone-auth.md`：

- 验证码只存 HMAC；
- 60 秒重发、5 分钟过期、5 次尝试；
- 手机号、IP、设备多维限流；
- 日志脱敏；
- 短信通道可插拔；
- 生产关闭 `exposeDevCode`；
- JWT 和 OTP pepper 不复用密钥。

## 5. 媒体安全

- 上传使用短期签名票据，限制对象 key、大小、MIME 和过期时间；
- 服务端以文件头/ffprobe 重新识别 MIME，不信任扩展名；
- 视频转码、抽帧、音频检测在隔离 worker 运行；
- 图片去 EXIF，防止位置和设备信息泄漏；
- 对上传文件做恶意文件扫描；
- 私有桶禁止公开列举，签名 URL 短 TTL、单资产、不可写；
- 删除内容时按保留策略延迟清理对象，避免任务重试引用失效；
- 记录素材来源、授权说明和版权声明，书籍封面需有授权依据。

## 6. 密钥与配置

| 配置 | 位置 |
| --- | --- |
| MySQL/Redis 密码 | Secret Manager / 环境注入 |
| 短信通道 token | Secret Manager |
| OAuth client secret | 适配器 Secret Manager |
| 平台 token 加密密钥 | KMS / Vault，不与数据库同机 |
| 对象存储访问密钥 | 最小权限 IAM |
| 服务间 token | Secret Manager，定期轮换 |

配置中不允许出现真实平台 token、手机号、验证码或签名 URL 示例值。

## 7. 内容与平台合规

- 书籍简介、书评、封面、作者照片和出版社素材必须有授权或合理使用依据；
- 不批量复制他人书评、洗稿或伪造作者观点；
- 商业推广内容按平台要求标识；
- 不使用“最权威”“保证提分”等无法证明的广告表述；
- 同一内容重复投放需按平台规则改写和限频，不能规避查重；
- 平台审核拒绝后不自动换号重发；
- 不承诺搜索引擎收录，不伪造阅读/点赞/粉丝数据；
- 不采集平台未授权用户数据。

## 8. 日志与审计

必须记录：

- 用户、账号、批次、任务、适配器请求 ID；
- 状态迁移、错误码、耗时、平台作品 ID；
- 授权、解绑、人工确认、媒体删除；
- 指标拉取和人工导入来源。

不得记录：

- 完整手机号、OTP、JWT、OAuth code、access/refresh token；
- 平台 cookie、二维码 ticket；
- 完整签名 URL 查询串；
- 正文全文、用户私信、评论内容。

日志保留 30 天，审计日志至少 2 年。

## 9. 可观测性

核心指标：

- 手机号登录发送/验证成功率；
- OAuth 授权成功率、token 过期率；
- 各平台发布成功率、审核拒绝率、人工接管率；
- 媒体上传/转码成功率和 P95 耗时；
- 指标拉取成功率和数据新鲜度；
- 平台错误码 Top N；
- 单平台任务积压和重试次数。

告警：

- 某平台连续发布失败；
- OAuth 回调失败激增；
- 对象存储上传失败；
- 短信通道失败；
- 任务积压超过阈值；
- 指标任务过期未执行。

## 10. 备份与恢复

- MySQL 每日全量 + binlog 增量；
- 适配器加密数据库单独备份，密钥单独托管；
- 对象存储开启版本/生命周期规则；
- 恢复演练验证 token 解密、任务重试和签名 URL；
- Redis 不承载唯一业务真相，丢失后可从 MySQL 重建锁/队列。

## 11. 网页自动化边界

本期不提供创作者网页后台自动化发布：

- 不操作发布页 DOM，不注入 Cookie，不复用浏览器 profile/storage state；
- 不保存平台网页登录二维码 ticket、密码或验证码；
- 不抓包、不逆向、不调用创作者中心私有接口；
- 小红书、视频号等未确认开放发布 API 的平台只做能力占位、人工任务和回填；
- 社区项目如 `biliup`、`social-auto-upload` 不作为生产依赖。

若未来平台提供新的官方开放 API，应按新能力补授权、额度、上传、发布、审核和取数证据，而不是恢复网页自动化。

## 12. 上线检查

- 已取得平台开发者应用和内容发布权限；
- OAuth 回调域名在平台白名单；
- 平台 token 加密、轮换和解绑验证通过；
- 视频转码规格与平台实测通过；
- 发布幂等、超时查询和审核状态验证通过；
- 指标接口与后台人工对账一致；
- 隐私政策、用户协议、内容授权和删除机制齐备；
- 没有平台凭据进入控制面数据库和日志；
- 未开通能力的平台默认禁用。

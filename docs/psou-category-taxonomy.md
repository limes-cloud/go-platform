## 归属规则

- 电影、电视剧、美剧、韩剧、日剧、综艺、纪录片、动漫、国漫、漫剧、短剧归 `影视`。
- `电影` 中按第一制片地区拆分：美国归 `美剧`、韩国归 `韩剧`、日本归 `日剧`；`纪录片` 优先保留在 `纪录片`，合拍片按首个制片地区归属。
- 短剧归 `影视/短剧`，不并入电视剧。
- 游戏按题材拆分：单机游戏按首个题材标签归入 `动作冒险 / 角色扮演 / 策略游戏 / 模拟经营 / 休闲益智 / 射击游戏 / 恐怖惊悚 / 体育竞速`。
- 以角色、偶像、宠物培育为核心，且简介明确标注养成/育成/恋爱养成的游戏归 `养成游戏`；仅在 RPG 或模拟经营中附带养成要素的不单独归入。
- `策略战略`、`即时战略` 并入 `策略游戏`；`恐怖丧尸` 并入 `恐怖惊悚`；`主机整合`、`模拟器整合` 归 `主机游戏`。
- `免费专区`、`免费国风` 统一归 `国风游戏`，首个标签同步改写为 `国风游戏`；DLC 解锁补丁、修改器、启动器等归 `游戏工具`。
- 主机与手游按平台归 `主机游戏 / 手机游戏`，不再按题材二次拆分。
- 课程、考试、教材归 `教育`；有声书、故事、听力归现有 `音频`。
- 安装包和工具软件归 `软件`；模板、字体、模型、源文件归 `素材`。
- 平台专用软件包优先归 `Windows软件 / macOS软件 / 安卓应用`；跨平台工具按用途归功能分类。
- AI 专用工具、提示词、模型、AI 工作流和 AI 教程归 `AI`；普通设计模板仍归 `素材`。
- 不设置“其他”分类，避免资源最终都堆进兜底目录。
- 分类树只允许一级和二级，不允许三级分类；资源必须挂在二级分类下。
